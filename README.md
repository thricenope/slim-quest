# 瘦身大作战 SlimQuest 🍬

> 在线体验：<https://thricenope.github.io/slim-quest/>（数据存在浏览器本地，换设备请用应用内导出/导入）

把减肥坚持变成消消乐的晚饭打卡游戏。**每天只记四件小事**：晚饭几点吃、吃了多少、喝没喝饮料、动没动——然后收宝石、攒连击、解锁里程碑。

## 玩法

- **今日**：点选式打卡，实时算分（规则全透明）。≥2 分 = 成功日收一颗宝石，≥6 分 = 完美日。**Q版小动物伙伴**陪你打卡——点一点吉祥物就能换：泡泡（麻薯）、团团（猫）、雪球（兔）、糯米（熊猫）、布丁（猪），伙伴表情会跟着当天判定变。
- **日历**：日历即棋盘。每个成功日是一颗六色宝石，**连续 3 天同色 = 一次「消除」**。点任意日期可补卡/修改。
- **成就**：里程碑之路从 1 天铺到 730 天（1/2/3/4/5 天、周末双杀、一周、两周、21 天、一月、百日、一年、两年…），实时显示「还差 N 天」，另有成就墙 23 枚徽章。
- **统计**：坚持第 N 天、成功率、当前/最长连击、近 14 天分数条形场、本月战况色块；数据可导出/导入 JSON。

## 快速开始

```bash
npm install
npm run dev      # 开发（默认 5188 端口）
npm run build    # 产出 dist/
npm run preview  # 预览生产构建
```

数据完全存在浏览器 localStorage（键 `slim-quest-v1`），无账号无后端；换设备用「统计 → 导出备份 / 导入恢复」。

## 技术栈

Vite + React 18 + TypeScript + zustand(persist) + framer-motion + canvas-confetti。字体自托管：ZCOOL QingKe HuangYou（标题）、Baloo 2（数字）。图标、宝石、吉祥物全部为手绘 SVG。

## 评分规则（UI 内同步展示）

| 维度 | 分值 |
| --- | --- |
| 晚饭时间 | 16点前 +3 · 17点 +2 · 18点 +1 · 19点 0 · 20点后 -2 · 没吃 +3（另 +2） |
| 食量 | 微微吃 +3 · 少吃 +2 · 适中 0 · 多吃 -2 · 很多 -3 · 非常多 -4 |
| 饮料 | 没喝 +1 · 无糖 0 · 含糖小杯 -1 · 大杯 -2 |
| 运动 | 每项 +2，每天封顶 +4 |

经验：成功日 +20、完美日再 +10、成就解锁 tier×25；等级曲线与称号见 `src/logic/level.ts`。
